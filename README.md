# João Lucas Moura de Oliveira

Backend engineer working in Go and TypeScript, with a focus on AI agents, context engineering and self-hosted infrastructure. Based in São Paulo.

I build systems for real operations: sales-planning tooling that reconciles data across ERPs, portals and spreadsheets; a Go + Svelte order and quoting system integrating shipping carriers and supplier stock; and agent infrastructure: a coding-agent harness, MCP servers, and context engines with permissions, provenance and audit built in.

## Selected work

**[Daedalus](https://github.com/Likas07/Daedalus)**: coding-agent harness in Bun/TypeScript, originally derived from Pi. Custom context compaction, schema-validated executable plans with dependency and file-conflict checking, task packets for subagents, managed worktrees, local GUI. Currently paused.

**[MercadoLivreMCP](https://github.com/Likas07/MercadoLivreMCP)**: read-only MCP server and Codex plugin for the Mercado Livre seller API. OAuth with PKCE, rotating refresh tokens, tested.

**[Competitive-Intelligence-Classifier](https://github.com/Likas07/Competitive-Intelligence-Classifier)**: dual-model text classifier (AutoGluon) that turns ambiguous import records into competitor product intelligence. Built for BASF's BI team; cut a 14-day manual analysis to minutes at ~95% precision, with human review for low-confidence predictions.

**[Archon](https://github.com/Likas07/Archon)**: fork where I'm working on workflow and worktree identity for deterministic AI coding runs.

Client and venture code (a commercial-planning system in production, an AI operator for marketplace sellers) is private.
